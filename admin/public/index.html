🔌 1. Conexão com o PostgreSQL

          
Banco, usuário e senha que o jogo usa. A senha fica no arquivo de senhas do PostgreSQL (pgpass.conf), não no projeto.

          

            
            
            
            
            
          

          

          

        


        
        

          
🧱 2. Instalar banco zerado

          
Cria o banco flyffweb vazio com toda a estrutura (e o usuário flyffweb_app, se faltar),
            usando a Conexão ao lado. Se o banco já existe, nada é feito.

          
Precisa do superusuário do PostgreSQL (o da instalação, normalmente postgres). A senha dele é usada só agora e não fica guardada.

          

            
            
            
            
          

          

          

        


        
        

          

            
💾 Fazer backup

            
Cópia completa (contas, personagens, itens, guilds, site) em data/backups/. Pode fazer com o jogo rodando.

            
            

            

          


          

            
⚠️ Zerar o banco

            
Apaga tudo e deixa o banco vazio, só com a estrutura. Antes, um backup automático é feito (…-antes-de-zerar.dump).
